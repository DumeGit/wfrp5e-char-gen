# Muster Roll painted banner

`muster-banner-v2.png` is original artwork generated with the built-in **imagegen** tool for the three standalone fantasy design previews. It remains outside the published app. The user's supplied Warhammer fantasy box-art image informed the art direction; its pixels, lettering, logo and composition were not copied.

Generated output was copied from the Codex generated-images directory into this project, leaving the source intact. The preview uses the full original image with CSS cropping, rather than modifying its pixels. There is no image-generation API/CLI dependency in the project.

Final prompt, verbatim:

> Use case: stylized-concept. Asset type: original painted wide masthead illustration for a Warhammer Fantasy Roleplay character-creator visual study. Inspired by colourful early tabletop fantasy box art: hand-painted gouache/oil, dense fine outlines, Renaissance fantasy heraldry, rich crimson, warm yellow gold, ivory, smoky forest green, aged printed illustration texture. Scene: a red-and-ivory regimental standard and a mounted armoured Empire-style knight with feathered helmet on the RIGHT side, medieval towers and timber-framed roofs in atmospheric distance, trailing banners and a few spear silhouettes to the LEFT. Brass sunbursts, cloth, leather, hand-forged armour. Wide panoramic landscape, about 3:1 aspect; the left/centre remains quieter and darker for a separately drawn title. A spirited, slightly strange, old-school fantasy painting, not a cinematic screenshot or photorealism. No text, lettering, logos, watermarks or UI elements. No futuristic or science-fiction armour, machinery, industrial metal panels, glowing technological interfaces, modern military kit or double-headed eagle. Do not reproduce any existing box-art composition or characters. This is decorative artwork; no rules or numerical information.

## Gilded W

`muster-w.svg` is drawn directly in vector code for the user's requested logo revision. The supplied Warhammer wordmark guides its angular W shape, now softened to antique gold with a thin oxblood bevel to match the surrounding design. Its viewBox centres the visible letter, and the folio uses a centred grid placement with even inset space. It is not an extracted official logo or an imagegen output. It replaces the shield/comet mark in the three fantasy iterations. The user requested removal of the glint; the emblem remains static. Both assets remain outside the published app.
