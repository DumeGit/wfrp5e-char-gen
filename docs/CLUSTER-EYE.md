Supplied Fourth Edition PDF (2021), SHA-256 `ec7d5a19124409fc45103a35a38b94d0792ccea1ef3af8ffc1a28ad5dd6d2e8a`. Read using MarkItDown, with printed pp. 8–9 checked visually. Extracted source material stays outside the published app.

## Reviewed scope and included content

The book provides seven generic advancement templates, Basic Forest Goblin and Drakwald Mancatcher (Giant Spider) foundations, optional Goblin/Orc Ride Skills, Arboreal and Spider Venom Arrows. Named Vish Venombarb, Bograt the Blasted, Blackhearted Nurd and Bugshot are excluded, along with setting prose, warband disposition and adventure encounters. No PC Species, Career or starting allocation is added.

Included: **Forest Goblin** and **Drakwald Mancatcher** (p. 9), plus **Soldier, Skirmisher, Elite, Chief, Warlord** (p. 8), **Shaman** and **Shaman Lord** (p. 9). The GM profile/template selector gates these entries only. Skirmisher remains distinct from the core template with the same name; neither overwrites the other. Existing shared Skill, Talent and equipment catalogues supply their choices.

- Forest Goblin retains all printed scores, Wounds 11, Weapon +7 and Armour 1. It does not inherit the different Fifth Edition core Goblin scores or extra Skill advances. Armour is not silently interpreted as a Shield. Its printed Animosity has no target; a visible parameter field and early issue require an explicit target before export. The optional Ranged +7 (25) names no weapon; this remains a source note, with explicit shared weapon selection rather than an invented equipment profile.
- Skirmisher applies table BS +5 and core Marksman's independent +5 BS. The named Bugshot example appears to include only one bonus; this discrepancy is shown in the app, without silently changing the table or importing the named character. Bow/Sling, their Skill and Stealth specialisations, and matching ammunition are explicit. One core ammunition pack provides 12 shots; Bow accepts Arrow (12), Sling accepts Lead Bullet (12) or Stone Bullet (12). Mismatches produce a focused issue before export.
- Current core Afraid, Infected and Flee! replace differing p. 19 summaries with individual Legacy explanations. Spelling corrections, unchanged numbers and unchanged effects do not receive blanket Legacy tags.
- Arboreal (p. 19) grants Agility Bonus SL to Stealth and Climb in woodlands. It is a sourced GM Trait and searchable reference, without permanent Skill changes or a Legacy tag for this compatible SL effect. Actual Trait descriptions appear in sheets; optional suggestions and conversion notes do not.
- Goblins may explicitly add Ride (Spider) or Ride (Wolf) +20; Orcs may add Ride (Boar) +20 (p. 9). Shared specialisations are available without extra PC advances. GM actions use the higher existing bonus, preserve source, and do not silently add a second creature sheet. These options follow the all-installed-options policy independently of the profile-book selector.
- Five searchable mechanical references cover applying templates (p. 3), Shaman spell lists (p. 8), Shaman armour and mount Skills (p. 9), and Spider Venom Arrows (p. 10). Profiles/templates remain outside global search. Venom arrows retain their specific contraction Test and nonlethal effect at 0 Wounds; they do not use the core Venom Trait's automatic Poisoned rule. No price, weight or purchasable pack is invented.

## Approved conversions (10 October 2026)

- **Drakwald Mancatcher:** core Large Size changes printed Fangs +7 to **+10**, with a Legacy note. Its printed 20 Wounds and other scores are retained. The GM must explicitly select the missing **Venom recovery Difficulty** in the app before export; no default is inferred. Core Venom automatically inflicts Poisoned on causing Wounds, separately from the venom-arrow rule.
- **Soldier, Elite, Chief, Warlord:** Leather uses core **Light (1 AP)**, Mail/Leather-and-Mail **Medium (3 AP)**, Plate **Heavy (5 AP)**. These edition adaptations have Legacy notes. Chief/Warlord choose an explicit armour and long weapon. Only Goblin foundations can select their optional **Ranged (Bow) +10**, which also grants one Bow and one Arrow (12) pack; removing the choice removes the entire package. Warlord's Longbow uses **Bow (2H)** with a Legacy note.
- **Shaman and Shaman Lord:** unspecified Arcane Magic becomes core **Spellcaster (Arcane)** with a Legacy explanation and an explicit Channelling Wind. Shaman gets exactly **3 Petty + 3 Arcane** spells; Lord gets **6 Petty + 9 Arcane**. The default Spellcaster +10 Skill fallback does not override their printed Channelling bonuses of +5/+20.
- Beastmen may choose **Arcane only**, or **Beasts, Death or Shadows** alongside Arcane spells within the same printed Arcane count. The selected Colour Lore requires its matching Wind. The template removes baseline armour; an applicable Skaven armour exception requires explicit equipment, without automatic casting immunity.
- Fimir lists remain reference-only because no Fimir foundation is installed. Ogre shared Lore/Wind restrictions remain enforced and visible before export. A GM can remove the incompatible template Spellcaster, add an explicitly permitted Lore, select a permitted Wind and use generic Arcane spells within the printed count. The core Ogre's existing printed Toughness Bonus discrepancy still requires its existing explicit choice after changes. No Great Maw spells are invented or granted by this template.
- Shaman Lord's **Instinctive Diction 2** becomes **one core rank** with a Legacy explanation. Combat Reflexes, Resolute, Inspiring and War Leader use their changed core effects with selective notes; unchanged Feint/Marksman and spelling corrections stay untagged.

## Maintenance and verification

`python scripts/build-cluster-eye.py` reproduces the complete approved import and frozen source audit. `npm run build` regenerates registry counts, GM content, startup/search libraries and offline assets. Do not edit generated libraries directly.

Template ammunition slots reuse core market entries through the existing equipment compiler, with an explicit linked weapon and compatibility issue. Printed Trait parameters use source-keyed `traitParameters` in GM drafts, preserving printed provenance and baseline calculations. Shared undo/save/export operate on the same calculated result. The separate `templateLore` field stores only the Beastman Shaman Lore choice; profile/filter state is not character data. Existing WIP drafts lacking new fields are rejected rather than silently migrated. Explicitly removing a template Trait allows a GM replacement of the same name without the removed grant overwriting it.
