# The Imperial Zoo in Bestiary

Enable **The Imperial Zoo** in **Profile & template books**. Choose **The Imperial Zoo** in the Category filter to browse the 43 generic foundations from the supplied Fourth Edition PDF, pp. 10–93. Same-name Core and supplement profiles are separate source choices.

The source records retain printed Characteristics, Wounds, attack Damage, Skill totals and Armour ratings. The book's parenthesised protection is combined soak. Tregara prints Armour 3 and combined soak 6 on p. 76. The workshop uses Armour 3 and Toughness Bonus 4, giving soak 7.

Shared Creature Traits use the Fifth Edition definitions. Flight uses Fly, Stride uses Sprinter, Swamp-strider uses Striding Gait (Wetland), and ranked Grim uses the core unranked Trait. Printed Hardy is represented by its core Talent where the baseline includes it. Existing Arboreal and Die Hard references retain their separate source context. Printed Swarm profiles already include their WS and Wounds adjustments.

Profile-specific attacks and abilities retain their source page. They are play references. Direct Appendix I Momentum and Test Difficulty conversions are used where applicable. The legacy Strength of the Pack and Disruption interactions retain their Fourth Edition context. Recalculate uses the existing Bestiary rules. Unusual printed variants may require manual edits.

Named specimens, pregenerated characters, encounter-only character builds such as the Spider-god Shaman, and appendix equipment and harvesting rules are outside this import. The book adds no Player creation options or shared search profiles.

The checked PDF fingerprint lives in the book manifest. Structured profiles and reviewed ability summaries live in the GM source pack and canonical description catalogue. Run `npm run generate:books` after editing the source records.
