# Marijan Mode

A separate, unrestricted one-page character editor at `dist/marijan.html`. The user authorised this mode on 9 October 2026, using Hammergen as an interaction reference, not a rules source or copied interface. The guided player creator and GM workshop remain independent.

## Editing and calculations

Identity, all ten Characteristics, resources, Skills, Talents, magic/prayers, equipment, extras and notes are on one page. Collections and notes use native collapsible sections with stable disclosure keys; the section menu opens a collapsed destination. Mobile retains labelled 44px fields and stacks the existing parchment/leather components. The desktop summary stays beside the page; intermediate widths put it below.

There are no Career/Species restrictions, prerequisites, Talent rank limits, starting allocations, XP prices or money deductions. Career level and tracker boxes are independent entered values. Finite numeric values, including individual Advances and deliberate negative values, are accepted. Technical save-format checks still reject invalid objects, non-finite values and unsafe entry keys. Export does not require rule compliance or complete choices.

Characteristics are Starting + Advances + Other. The optional permanent Talent setting adds each printed +5 Characteristic benefit once and Fleet-footed's +1 Movement. Extra unrestricted ranks do not invent further benefits. Fate/Fortune and XP are entered independently; Luck never silently changes Fortune. A recorded crypto/rejection-sampled 2d10 roll replaces each Starting value with that Species modifier + dice sum, preserving Advances/Other; its die faces and timestamp are saved. Imported roll logs are not verified randomness.

Wounds reuse the shared core Size calculation; Hardy applies its printed benefit once. Tiny remains unknown without a manual value. Carrying capacity uses the existing Sturdy interpretation selector, Strong Back's first/two-rank effects and approved Ogre multiplier. The automatic equipment total is **listed unit Enc × quantity**, excluding stored items and coins; packing/worn reductions and load penalties are not applied. Armour sums recorded worn/equipped profiles by printed location, without enforcing layering restrictions. Unknown carried weights/AP stay unknown. Weapon Damage retains its entered printed expression or manual value. Traits, mutations, runes, Cants and other situational effects are recorded references, not automated effects.

Wounds, Movement, capacity, listed Enc, armour locations and Skill totals have explicit Auto/Manual controls. Manual values survive subsequent recalculation. Clearing a manual numeric field returns it to Auto. Switching Species or Career never deletes entries or grants equipment/abilities. **Species defaults** previews and explicitly applies Species Characteristic modifiers, Fate, Fortune, base Movement and Size; it preserves Advances, Other, entries and manual overrides, and grants no starting Skills/Talents.

## Content and references

`marijan/catalogue.mjs` assembles all integrated non-variant PC packs once, expands their existing Skill/Talent choices and reuses `spellChoices`, Cants, techniques, runes, equipment and the reviewed GM Trait/mutation options. Explicit variant Career records are included separately without repeatedly assembling the entire library. No PDF extraction or separate authored equipment list is introduced. Existing same-name precedence and withdrawn profiles follow the shared catalogue. Inline name search and Book selectors narrow browsing only; no selected-book gate limits this mode. Exact/prefix name matches lead, and results expand in small batches. Search fields and source filters never enter saves.

Known entries retain their source and selective Legacy metadata. Species/Career references also expose their approved adaptations. Entry details allow character-local description/profile overrides. Shared all-book search remains reference-only and unchanged. Custom Skills, Talents, spells/prayers, Cants, weapons, armour, Trappings, Traits, mutations, runes and techniques have user-defined names/text and no invented printed source or automatic effects.

## Saves, copying and export

Schema 1 has type `wfrp-marijan`; `marijan/model.mjs` validates its structural shape independently of creator legality. Selected entries contain reference snapshots and character-local values. Local autosave uses `wfrp-marijan-v1`; named saves use `wfrp-marijan-v1-saves`. Isolated `?verify=1` storage appends `-verification`, including for copy-source selection. Local storage failures advise/use JSON backup instead. Save character updates its named local entry and downloads a JSON backup. Load can import JSON or choose a local named save. Wrong-tool save files are rejected. Undo/Redo covers edits, additions, removals, defaults, loads, copying and New character; text/number input edits are grouped rather than redrawn on each keystroke.

Copy player character accepts this device's player draft or a current player JSON. It calculates the existing player snapshot through `catalogForCharacter` and `characterResult`, then creates a **new** Marijan draft without writing to the original. Existing Characteristic bonuses are included with automatic Characteristic/Movement Talent effects disabled, Skill totals and derived fields retained as manual snapshots, and copied equipment kept at its resolved unit values. The original creation/XP history is not manufactured as unrestricted purchase records. There is no conversion back to legal guided creation.

PDF uses the supplied editable character-sheet template and local pdf-lib. All entered values, ranks, overrides, sources, custom descriptions, extra entries, notes and dice logs appear in a paginated appended Marijan record. Sheet space limits abbreviate or redirect to that complete record instead of silently dropping content. The record explicitly identifies unrestricted/manual creation and does not claim verified XP history. The exact entered tracker and Corruption values remain in the record even if the supplied sheet has fewer boxes. The JSON backup preserves all character data.

## Shared components and checks

Primitive `esc`, `score`, `button`, `field` and `select` controls are in `dist/controls.mjs`; GM controls re-export them. Wounds live in `dist/creature-calculations.mjs`, re-exported by the GM model. Mixed-weight PDF wrapping/drawing is in `dist/pdf-text.mjs`, re-exported by the GM helper. All tools share `creatorSwitch`, design tokens/skin, headings/emblem, disclosure capture/restore, reference search, install control and PWA runtime. Marijan-specific CSS owns layout only and uses the Black Banner palette. Its modules load only from its entry point; PDF export and player-copy calculations load on demand.

Focused checks: `node --test tests/marijan.test.mjs` and `npm run test:ui:marijan`. Local Playwright covers desktop/mobile editing, inline additions, overrides, Undo, saving/reloading, actual PDFs and copying without changing the player draft. Shared component or release changes follow `docs/TESTING.md`. No GitHub tests or deployment actions are added.

Initial verification (9 October 2026): the release check passed 404 Node tests and 86 desktop/mobile browser cases; final focused checks passed 10 Marijan Node tests and 10 browser cases after the last refinements. The supplied editable sheet and appended record were rendered and visually checked, alongside desktop/mobile editor screenshots. No push or deployment was performed.
